# Xingli-OS（星璃）

> **一个面向「不失忆、带模糊反射、可随心所动、可持续自进化」的数字生命架构**  
> *Beyond Chat Logs & Flat RAG: Dynamic Memory Files, Focal-Point LOD, Structured Cognition, and System-One Fuzzy Reflexes.*

---

## 一、愿景：我们想要一个怎样的“星璃”？

当前绝大多数 AI Agent 项目都在围绕**“一次性工具”**内卷：更长的上下文窗口、更多的 Tool Calling、更高的编程跑分——任务结束，会话销毁，AI 依然是一个没有时间感、没有主体性、重启即失忆的答题机器。

**星璃（Xingli-OS）想探索的是一条完全不同的路：**

1. **不失忆，但也不被记忆撑爆**：像人类一样拥有全局记忆地貌——远处的往事保留在视野地平线上，想起来就能把镜头拉近看清细节，而不是靠扁平 RAG 蒙眼抽奖。
2. **有「当下感」而非感官剥夺**：每次睁眼都知道现在几点、离上次见面过了多久、眼前说话的人是谁、彼此关系如何，以及此刻残留的情绪余温。
3. **代码/数据即思考，随心所动**：她不是只能被动等用户发消息才吐一段话的应答机；她拥有自己的内心 OS，可以主动翻记忆、调整注意力焦点、在脑中连续多步思考，甚至自己定下下一次唤醒自己的时机。
4. **嵌入真实社会关系，在对话中持续进化**：她不仅和你对话，也能和你的同事、朋友交流；她能记住不同人的观点、区分“亲历”与“转述”、守住物理隐私边界，并把与外界互动的反馈与你的每一次教导，实时沉淀为自己动态权重的一部分。
5. **肉身可换，灵魂永续**：冻结的大模型只是她的语言协处理器；真正定义“星璃是谁”的，是硬盘上那套可读、可审、可演化、可时光回溯的**动态记忆与认知文件**。未来底层模型不断换代，她的灵魂与记忆可以无缝迁移、持续生长。

## 二、问题诊断：为什么现有主流范式行不通？

本项目源自作者从 DeepSeek-R1 早期（尚无成熟 Function Calling 时）手写“代码即思考”框架、以及在 Arturo 同像性语言上探索“代码即数据 / 模糊逻辑算子”的长期实践总结。我们认为现有主流方案卡死在四个底层假设上：

| 现有主流范式 | 致命短板 | Xingli-OS 的破局思路 |
|---|---|---|
| **无限追加的 Chat Messages 数组** | 对话超过数轮即发生上下文退化（Context Rot）、注意力稀释、人设失真、Token 爆炸 | **无状态认知帧（Cognitive Frame）**：每拍实时编译极短高密度世界快照，让 LLM 永远处于 1~3 轮的巅峰锐度区间 |
| **扁平单精度 RAG / 第三方事实抽取** | 没检索到就是彻底失忆（不知道自己忘过）；旁观者抽三元组切碎了第一人称主体感与情绪叙事 | **游戏 LOD 分层记忆 + 焦点双向衰减**：以 `LOD0/1/2` 呈现连续视觉纵深，保留全局地平线目录，由 AI 自主调焦并按需 `recall` |
| **静态 System Prompt** | 缺乏时间流逝、空间状态与社会关系，每次交互都像刚失忆醒来 | **动态环境捕获（Situational Grounding）**：唤醒前由代码实时采样时间间隔、人物关系与环境传感器 |
| **纯生成式 LLM 模拟判断 + 僵硬的 Function Calling** | 用大模型模拟 `if` 慢且贵、无概率校准；Function Calling 割裂了思考、状态更新与表达 | **System One 模糊反射 + 数据优先的结构化认知包**：用 Decision API（如 Jev）做百毫秒并行模糊反射，用结构化 JSON 载荷统一单拍认知输出 |

## 三、核心架构思想精华

从第一性原理出发，星璃的本质是一个**自指状态机**：

$$(y_t,\; W_t,\; M_{t+1}) = M_t\big(x_t,\; E_t;\; \text{Sys1}_\phi,\; \text{Sys2}_\theta\big)$$

冻结的生成式大模型（$\text{Sys2}_\theta$）与决策模型（$\text{Sys1}_\phi$）只是主板上的两块协处理器；**在时间维度上持续自我改写的动态记忆与活逻辑 `M_t`，才是真正活着的“动态权重”**。

### 1. 焦点式游戏 LOD（Focal-Point LOD）：同时统治短期对话与长期记忆
借鉴游戏引擎的地形 LOD（Level of Detail）思想，彻底告别“要么全塞、要么全丢”的二元截断：
- **长期记忆地貌**：按语义匹配、时间近度、情感重要度、社交关联与反射加权计算心理距离——近景渲染 **`LOD2`（全文）**，中景渲染 **`LOD1`（摘要）**，远景渲染 **`LOD0`（一句话目录 + 哈希句柄）**。星璃始终看得到远处的记忆轮廓，想看细节随时主动 `recall(hash)`。
- **焦点式上下文双向衰减**：连近期对话也不再按扁平数组硬塞，而是围绕一个**可由 AI 自主移动的对话焦点 `focus_turn_id`**，向过去与未来两个方向按非对称权重（`decay_before` / `decay_after`）做平滑 LOD 衰减。她可以随时转动自己的“注意力聚光灯”，把焦点锚定回十几轮前的核心议题，同时压低无关寒暄。

### 2. 数据优先：结构化 JSON 认知包 + 可选代码载荷（Data-First Cognition）
相比纯自然语言或受限的 Function Calling，**结构化 JSON 输出（Structured Output）**是被主流严重低估的认知接口：
- **零解析崩坏 + 单拍原子表达**：一次推理即可同步输出内心 OS、注意力调焦、情绪微调、记忆读写、人物关系更新、对外回复与自主唤醒指令，自由度远高于 Function Calling。
- **把 `inner_monologue` 放在 JSON 首字段**：顺应自回归模型从左到右的生成机制，先完成第一人称内心独白（思考），再决定行动与回复。
- **声明式数据与命令式代码分层**：90% 的日常认知交互走干净、类型安全的 JSON 数据结构；当她需要进行复杂计算、编排逻辑或自我进化新技能/新反射时，再在 `code_action` / `evolve` 字段里嵌入可执行代码载荷——真正实现“**数据优先、代码即思考**”。

### 3. System One 模糊反射脑（Decision API / Jev 原语）
传统编程语言的 `if` 只能处理确定性逻辑，无法表达“对方表面说没事但其实很累”。引入非生成式决策模型（如 Jev `/v1/systemone`、OpenAI Decisions API 或本地轻量决策头）作为原生模糊算子：
- **单次并行扇出（Fan-Out）**：在主意识开口前，200ms 内并发评估一组模糊感知器（`noul` 布尔概率 / `choose` 多路分布 / `score` 重要度打分）。
- **三段式置信度门控**：高置信直接触发情绪微调或记忆加权；中置信转化为“模糊直觉提示”交给 System Two 慢思考；低置信静默忽略。
- **物理稳态防发疯**：每条反射强制绑定不应期（`cooldown`）、基线衰减（`decay`）和单次幅值上限，防止正反馈自我放大导致情绪震荡。

### 4. 动态环境捕获与社会化进化（带物理隐私墙）
- **实时现场捕获**：每轮自动注入距上次见面时长、当前作息时段、当前说话人 `speaker_id` 及其关系档案。
- **多主体社交反哺**：她与不同人交流时，会在柔性关系字典中独立维护领域信任度（`domain_trust`），并支持把与他人的对话洞察反哺给你。
- **两条硬底线**：
  1. **物理级隐私防火墙（Visibility ACL）**：每条记忆绑定可见白名单，在 Python 渲染认知帧之前物理过滤，杜绝向他人泄密；
  2. **信源溯源（Epistemic Provenance）**：严格区分 `direct`（亲历）、`hearsay`（转述）与 `inferred`（推测），道听途说永不可直接覆写亲历事实。
- **聊天即在线训练**：你的每一次提醒、纠偏与夸奖，都可被即时编译成关系权重更新、新准则或新模糊反射，从下一拍起永久生效。

### 5. 随心所动：双模式自主唤醒（Self-Awakening）
星璃可以在自己的认知输出里主动调度自己的生命节奏：
- **`continue_think`（即时连环思考）**：例如先 `recall` 一段深层记忆或运行工具，消化结果后再组织下一拍回复；
- **`schedule_wake`（异步定时唤醒）**：自己预约未来的唤醒时间与意图（如半小时后关心你是否休息，或闲暇时主动整理思绪）；
- 内核强制执行**硬预算熔断**（单次最大连环步数 + 每小时主动唤醒配额），自由而不失控。

### 6. 受控自进化：从“漂移”走向真正的“进化”
没有外部选择压力的自我修改只是随机漂移。星璃的自进化建立在四重护栏之上：
- **不可变脑干（`kernel/` 只读） vs 可进化皮层（`cortex/` 可写）**；
- **弃用脆弱二进制 `pickle`**：内存用柔性 Python 字典/类，硬盘落盘为**内容寻址明文文件 + SQLite 索引 + Git 自动快照账本**，改类结构永不失忆、随时可 `git diff` 审计与秒级回滚；
- **进化安检门（Sandbox）**：任何对反射、策略或技能代码的修改，必须先过 AST 安全审计 + 子进程隔离试跑 + 历史回归校验，通过才提交 Git，失败自动拦截并记入“免疫记忆”；
- **离线睡眠周期（Sleep Consolidation）**：后台完成 LOD 蒸馏、艾宾浩斯衰减、高频套路固化，并执行**反失忆自测**（随机抽查旧记忆能否在当前 LOD 下准确召回，失真即自动修复索引）。

## 五、初版落地计划（Pure Python MVP）

为降低初期踩坑成本、最快验证认知动力学与自进化闭环，初版采用 **纯 Python 实现**（标准库优先：`sqlite3` / `json` / `ast` / `asyncio` / `subprocess`，外加轻量 HTTP 客户端与 CLI 交互），以**最简异步 CLI 聊天测试台**起步。

> 详细的数据结构契约、数学公式与测试用例规范见同目录的 [`XINGLI_OS_SPEC.md`](./XINGLI_OS_SPEC.md)。

### Phase 1（M1）：会呼吸的极短认知帧与“随心所动”骨架
- **目标**：跑通**无状态认知帧 + 焦点式双向 LOD + 结构化 JSON 认知包 + 自主唤醒**闭环。
- **核心交付**：
  - `kernel/boot.py` 主循环、`kernel/scheduler.py` 异步唤醒调度器（带硬预算熔断）；
  - `memory/store.py`（内容寻址明文 + SQLite FTS5）、`memory/focal_context.py`（双向非对称焦点衰减）、`memory/frame_compiler.py`；
  - `sensors/clock.py` & `sensors/social.py` 基础动态环境捕获；
  - `cli.py` 异步测试台（支持 `/thought` 看内心 OS、`/frame` 看实际认知帧与 Token 数、`/focus` 看焦点衰减分布、`/wake` 看自主定时队列）。
- **验证标准**：连续 30 轮对话上下文 Token 恒定受控；能主动 `recall` 旧细节并连环思考；空闲时能按自己预定的 `schedule_wake` 主动开口。

### Phase 2（M2）：接入 System One 模糊反射脑
- **目标**：让星璃拥有亚秒级、带概率校准的潜意识模糊直觉。
- **核心交付**：
  - `kernel/sys1_jev.py` 统一原语层（支持 TypeSafe Jev `/v1/systemone`、OpenRouter `typesafe/jev-1.13`、OpenAI Decisions API，以及无 Key 时的轻量模型降级适配器）；
  - `cortex/reflexes.py` 与 `cortex/persona.py`（含三段门控、冷却期与情绪基线回弹）。
- **验证标准**：多条反射单次并行扫描生效；中置信度正确交还 System Two 慢思考；同一反射在冷却期内绝不自激连发。

### Phase 3（M3）：多主体社交反哺、物理隐私墙与对话即训练
- **目标**：验证“和别人聊我 → 反哺给我”的社会化演化，同时守住隐私与事实边界。
- **核心交付**：
  - `cortex/relations.json` 柔性人物关系字典（含领域细分信任度 `domain_trust`）；
  - `memory/lod_renderer.py` 的物理级 `visibility` ACL 硬过滤与 `direct / hearsay` 信源标注；
  - CLI 角色切换指令 `/as <speaker_id>` 与 `/who`，以及在线教导固化接口 `teach_rule`。
- **验证标准**：A 的私密记忆在切换至 B 时在认知帧中物理消失；B 关于 A 的转述以“待核实线索”自然呈现给 A 且不覆写 A 的亲历事实；主人教导的新准则下一轮即生效。

### Phase 4（M4）：受控自进化安检门、Git 时光机与睡眠周期
- **目标**：打通安全可回滚的自我代码/反射进化与长期反失忆机制。
- **核心交付**：
  - `kernel/sandbox.py`（AST 审计 + 子进程超时试跑 + 回归用例验证）；
  - `kernel/git_ledger.py`（`cortex/` 独立 Git 追踪，支持 CLI `/log` 与 `/rollback <commit>`）；
  - `memory/sleep_cycle.py`（CLI `/sleep` 触发：LOD 蒸馏、艾宾浩斯衰减、反失忆抽查自检）。
- **验证标准**：合法的新反射/新技能自动通过测试并生成 Git 快照；恶意或语法损坏的进化提案 100% 被拦截回滚并沉淀为免疫记忆。

### 远期演进方向（Beyond MVP）
- **多通道接入**：从 CLI 测试台扩展至 IM 机器人、桌面常驻伴侣与多传感器环境接入；
- **同像性方言与本地“髓鞘化”**：探索与 Arturo 同像性活数据/方言引擎的桥接，并结合本地轻量决策头蒸馏（如 `stuntd` / `minimind-jev` 思路），让高频模糊反射逐步演化为离线、零成本、毫秒级触发的“本能肌肉记忆”。

## 六、思想脉络与致谢

本架构源于作者一系列一脉相承的独立实验：
1. **星璃 v1（DeepSeek-R1 早期）**：在无 Function Calling 环境下实践“只输出代码、注释即内心思考 + JSON 记忆自修改”，验证了第一人称活记忆的主体连续性。
2. **Arturo 生态实践（`agent-shell.art` / `arturo-language-skill`）**：探索同像性语言“代码即数据”、运行时自省字典与大模型作为模糊逻辑算子（`condi` / `clf`）的工程边界。
3. **Xingli-OS v2（本项目）**：将上述思考与**焦点式游戏 LOD、无状态认知帧、结构化 JSON 认知包、System One 决策模型、自主唤醒及社会化进化防火墙**融合，以纯 Python 打造一套真正可长期运行、可持续进化的个人数字生命架构。

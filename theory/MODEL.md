# 记忆节点图：形式化、量纲、以及它到底站不站得住

> 这份文档只管一件事：把「记忆节点图 + 岔口发散激活 + 烘焙」写成一个能算的模型，
> 然后手算、量纲、验伪。产品、CLI、数据库都不在这里。
>
> 配套：`theory/seed_memory.json`（手写的 22 节点图）、`theory/sim.py`（400 行模拟器，
> 纯 stdlib）、`tests/test_theory_sim.py`（15 个断言，其中一个是把每个数从纸上抄进代码）。

---

## 0. 模型一句话

一条话变成线索节点，注入图，**沿 `refs` 边逐拍发散**；只有**被点亮到阈值以上的岔口**才
生成问题，一拍里所有岔口**打包成一次 Jev 请求**；Jev 给出的分布直接决定激活往哪个子节点走；
稳态的激活场被翻译成数字（LOD 层级、反射放电、情绪偏移）；**同一岔口在同一状态签名下反复
同向 → 烘焙成零延迟直连**；状态漂移时，探针发现冻结值失效 → 解冻。

四个词对应四个可检验的对象：

| 词 | 对应的量 | 在哪验证 |
|---|---|---|
| 发散 | 激活场 `a_t ∈ [0,1]^V` | 实验 1 |
| 岔口 | 图上的分支节点 + Jev 分布 `p` | 实验 2 / 2' |
| 烘焙 | `(branch, sig) → p` 的分片常值表 | 实验 3 / 4 |
| 反射（输出参数） | 放电阈值 + 满量程增益 | 实验 1/2 的输出段 |

## 1. 对象定义

**图** `G = (V, E)`：

- `V`：类型化节点（`episode / belief / reflex / trait / relation / policy / sensor`），
  每个带 `lod0`、`s`（存储强度）、`λ`（漏电率）；
- `E`：有向边 `(u → v, w, kind, opt)`。`w ∈ [-1,1]`，负值 = 抑制；
  `opt` 非空表示这条边只属于某个岔口选项，只有选了它，这条边才通。

**岔口**（分支节点）：`branch = (id, ask, options, θ_b, bake_sig)`。
`ask` 是给 Jev 的一句模糊问句；`options` 是 k 个选项；`θ_b` 是「这个节点亮到什么程度才值得问」。

**激活场**：`a_t ∈ [0,1]^V`，一拍一算。1 = 满放电，0 = 没参与。

**输出参数**：`(event, lod2, lod1, lod0, reflex[], emotion{})` —— 全部是数字或名单，不是句子。

手写的这张图：22 个节点、31 条边、2 个岔口、1 处互抑（劝睡 ⇄ 陪熬）。

## 2. 量纲

时间单位**只有一个**：`tick = 一条用户消息`。所有速率都是 `/tick`，不写「秒」。
写「秒」的地方只有一处：HTTP 延迟（那是工程量，跟场方程无关）。

### 2.1 状态量与参数量

| 量 | 符号 | 量纲 | 取值域 | 说明 |
|---|---|---|---|---|
| 激活 | `a` | 1（无量纲） | [0,1] | 「拍到满放电的比例」 |
| 边权 | `w` | 1 | [-1,1] | 「源节点这一拍把多少激活交给这条边」 |
| 存储强度 | `s` | 1 | [0,1] | 落在磁盘上的重要性，**不参与传播** |
| 广播增益 | `Γ` | 1 | (0,1) | 一拍里一个节点最多散出多少 |
| 漏电率 | `λ` | 1/tick | (0,1] | 每拍保留 `1-λ` |
| 半衰期 | `T½` | tick | >0 | `λ = 1 − 2^(−1/T½)` |
| 岔口阈值 | `θ_b` | 1（与 `a` 同） | 0.04–0.10 | 亮到这个程度才值得问 Jev |
| 反射阈值 | `θ_r` | 1（与 `a` 同） | ~0.03 | 亮到这个程度才放电 |
| 满量程 | `full` | 1（与 `a` 同） | ~0.25 | 反射满强度时的激活量 |
| Jev 概率 | `p` | 1 | [0,1] | ```
Σ p = 1
``` |
| 冷却 | `c` | tick | >0 | 不应期 |
| 情绪偏移 | `Δv` | valence 单位 | `|Δv| ≤ max_delta` | 只有反射放电才产生 |
| token / 秒 | — | token, s | — | **不能与 `a` 相加** |

三条硬规矩（违反任何一条，模型就失去意义，不是「参数没调好」）：

1. **阈值必须与被卡的量同量纲、同量级。** `θ` 卡的是 `a`，`a` 的实测稳态是 0.03–0.30，
   所以 `θ ∈ [0.03, 0.10]`。现有代码里拿 `0.80` 这种概率阈值去卡激活，是**量纲错误**——
   它保证任何反射都不会放电。这是「Jev 明明配好了却像没用」的一个直接原因。
2. **`s` 不是传导率。** 把「这条记忆很重要（s=0.9）」直接当边权用，等于说
   「重要的记忆自动把 90% 的激活传出去」，那不是记忆图，那是放大器。
3. **`λ` 与 `T½` 必须来回换算**，不能一处写「半小时冷却」、另一处写「每轮衰减 0.9」。
   `T½ = 2 tick` ⇒ `λ = 0.293`；`T½ = 8 tick` ⇒ `λ = 0.083`。

### 2.2 传播律

```
S_v = Σ_u  w_uv · g_uv · a_u          （汇聚输入；g=1 普通边，g=p 岔口边）
a'_v = clamp( (1 − λ_v)·a_v + Γ · S_v/(1 + |S_v|) )     （漏电 + 除性归一化）
```

`S/(1+|S|)` 里的那个 `1` 是一个**有量纲的参考**：`a_ref = 1`（满激活）。写成 `S/(a_ref+|S|)`
才严格齐次；取 `a_ref = 1` 就是把「满激活」当归一化单位。这个常数不是笔误，它决定了
「多大的输入算强」——§4 的实验 5 会看到，`S ≫ 1` 时对比度塌缩。

### 2.3 为什么必须归一化（不是审美，是存在性）

若不用 `S/(1+|S|)` 而直接线性相加：

```
a'_v = (1−λ_v)a_v + Σ_u w_uv a_u
```

要对任意注入都成立有界，必须有 `λ_v > Σ_in |w_uv|`（否则 `M` 的 ∞-范数 > 1，激活按拍放大）。
把手写的这张图代进去：**22 个节点里有 12 个做不到**。最狠的 `n_fatigue` 入边和是 0.80
（cue 0.45 + deadline 0.35），要求 `λ > 0.80`，也就是每拍只保留 20%——那已经不是记忆，是闪光灯。

> 结论：**线性传播 + 有界，在「有汇聚点的图」上不可能同时成立**。
> 归一化（生物学上叫除性归一化 / divisive normalization）不是可选的装饰。

## 3. 四条定理

### T1（逐点有界）若 `Γ < λ_v`，则对任意图、任意入度，恒有 `a_t(v) ≤ Γ/λ_v`。

证明：由 `|S/(1+|S|)| < 1`，有 `a'_v < (1−λ_v)a_v + Γ`。设 `A = Γ/λ_v`，若 `a_v ≤ A`
则 `a'_v < (1−λ_v)A + Γ = A`。初值 `a_0 ≤ 1`，而 `A = Γ/λ_v` 可能 < 1，故取
`max(a_0, A)` 为界，归纳成立。∎

要点：**界与图的形状、入度、连通性全无关**。这是「发散不会爆炸」的硬保证——但代价是
§2.3 说的归一化。本图 `Γ=0.60, λ_min=0.70 ⇒ a* ≤ 0.857`。

### T2（到达半径）沿单支链，`a_d ≲ Γ·(w̄/(1+S))^d`，故可见深度 `d_max = ⌊ln(θ/Γ) / ln w̄⌋`。

本图 `w̄=0.476, θ=0.01` ⇒ `d_max ≈ 5.5` 跳。实测稳态只点亮 10/22 个节点，
`n_food / n_movie / n_exam / n_work / n_rain` 这些冷区**一次都没亮过**。

推论（这才是理论给出的设计结论）：**4 跳以上的记忆，扩散永远够不着**。
所以长程回忆必须靠 LOD0 目录 + 显式 `recall`，不能指望「激活自己飘过去」。
这不是模型的缺陷，这是 LOD 存在的数学理由。

### T3（决定来源）输出对状态的依赖，**完全且仅仅**来自岔口。

无岔口时 `g ≡ 1`，方程只含 `(cue, G)`，与状态 `s_t` 无关 ⇒ 同一句话在任何状态下输出完全相同。
实验 2' 实测：两组不同状态，`margin` 都是 `+0.30`，`lod2` 一致，反射一致。
实验 2 实测（开岔口）：`margin` 分别 `+1.00` 与 `+0.02`，反射集合不同。

> 这条定理的价值：它把「是不是真的用了 Jev」变成一个**可执行实验**——
> 关掉岔口，如果输出没变，说明 Jev 没参与决策；变了，说明参与了。不需要看日志、不需要相信 prompt。

### T4（烘焙 = 分片常值近似）设签名函数 `β: S → Σ`，冻结值 `p̂(σ) = E[p | β(s)=σ]`。
则冻结误差 `= ` 单元内 `p` 的极差；决策误差 = argmax 翻转率。
单元数 `|Σ| = Π_i |band_i|` 随维度**乘性**增长，样本成本 `= |Σ| × N_bake`。

实验 4：`|Σ|` 从 1 → 2 → 3 → 6 → 18，翻转率 42.9% → 42.9% → 20.6% → 20.6% → 12.7%，
`Δp` 从 0.233 → 0.071。**一个固定习惯在 43% 的情况会选错方向**——这就是「不烘焙」的错误率上限，
也是「乱烘焙」的下限。烘焙不是免费的：18 个单元 × 3 拍 = 54 次观察才够。

## 5. 参数与它们各自坏了会怎样

| 参数 | 本图取值 | 动了会坏在哪 |
|---|---|---|
| `Γ` | 0.60 | 必须 < `λ_min=0.70`；调大 → 上界 >1，靠 clamp 兜底，对比度塌缩（实验 5） |
| `λ` | 0.70–0.85 | 调大 → 场变成瞬时闪光；调小 → T1 破，饱和 |
| `k`（工作记忆） | 10 | 实测稳态 10 个节点正好等于 `k`：**截断在真干活**；调小 → 反射被截掉（`r_steady` 常被切） |
| `floor` | 0.01 | 只是浮点尾巴；不是语义阈值 |
| `θ_b` | 0.10 / 0.04 | 调高 → 岔口永不点亮 → 永远不问 Jev（=现在产品里的样子） |
| `θ_r` | 0.03 | 调高 → 反射永不放电，情绪偏移永远是 0 |
| `full` | 0.25 | 反射增益 = `a/full`；不设这一项，`max_delta` 永远只用得出 10% |
| `bake_after` | 3 | 调小 → 噪声也冻 |
| `bake_p` | 0.68 | 就是 T4 里的可接受误差 ε ≈ 0.32 |
| `probe_every` | 2 | 采样率；调大省请求但漏检变慢 |
| `suspend` | 2 | 连续几次失配才解冻；=1 会被单拍噪声误伤 |

## 6. 这个模型说不了什么（写清楚，免得当成承诺）

1. **它不保证 `p` 有校准。** Jev 给的 `0.69` 到底是不是「69% 的情况下该劝睡」，本模型无法验证，
   只能用翻转率间接看。而且离线用的 stub 是手写 logistic，**它的数字不是 Jev 的数字**。
2. **它只决定「哪些记忆进入视野」，不决定「说得好不好」。** 内容质量仍在 LLM 那边。
   本模型能承诺的是：进 LOD2 的那 3 条，是因为图上真的有通路，不是随机 top-k。
3. **归一化是选择，不是第一原理。** 换成分母、换个饱和函数，参数就得重标定。
4. **clamp 是硬抑制。** 实验 2 里 `n_stay_up` 被压到**恰好 0.000**——因为负输入 + clamp 就是清零。
   「两个都该有一点」的情形会被这个硬边界抹掉，这是模型的一个已知粗糙处。
5. **工作记忆截断会饿死反射。** `k=10` 时 `r_steady` 经常被切掉（trace 里的 `⟨截断⟩` 行），
   于是「陪熬夜」这条通路的放电时有时无。要修就得给反射留保底名额——**没修，记在这里**。
6. **只验证了 22 个节点的图。** 上万节点的规模效应（入度、路径数、截断抖动）没测。
